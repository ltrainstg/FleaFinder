# FleaFinder
I hope to create a react app here that helps with finding fleas in silksong. Eventually with links to a youtube or online guide. 


# Sources 

YAML source: https://vite.dev/guide/static-deploy




## Steps 

1. Follow guide to get CI/CD pipeline done
2. Get python script to read a save file and get yes/no on all fleas/
3. React app that takes in save file and runs python script. 
4. Use the result of the script to link to other sources
5. Do a playthrough of SS and edit a video with all fleas from a bench. 
6. link to that video instead and create a youtube account for the 1 video.
